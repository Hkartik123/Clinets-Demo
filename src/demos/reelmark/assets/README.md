# Reelmark media assets

The WebP files in this folder are local concept-photo posters sourced from Unsplash. They are photographs, not video clips. Source photo IDs are recorded in `assetSources.ts`.

The Reelmark demo has a `videoSrc` slot for a separately supplied, licensed MP4 or WebM on each item. Until unique footage is supplied, the interface shows the poster and labels the preview as a still-image concept; it does not claim that a video is playing.
